
# PoseTuner

A player pose adjustment mod for Minecraft 1.20.1 Forge.

## ✨ Features

- Freely adjust the rotation and position of each player body part
- Supports the head, body, arms, legs, and the overall model
- Supports third-person pose preview
- Customize poses via the config file

## 📦 Installation

Requirements:

- Minecraft 1.20.1
- Forge 47+
- Java 17

Place `PoseTuner.jar` into `.minecraft/mods/`.

## 🎮 Usage

By default, press `P` to toggle forced pose preview on/off.

Config file:

`.minecraft/config/posetuner.toml`
